Good questions

Clear answers, before you dive in.

ALLEY Cloud is designed around tools you control. Here are the key things to know about the concept and what a live service needs behind the scenes.

Ready to get started? →
Is the AI really powered by Google Gemini?

The concept is designed for a Gemini-powered assistant. This downloaded website is only a front-end demo; connecting Gemini requires a server-side endpoint, a valid API key, usage limits, and error handling. Never place a production API key in browser JavaScript.

Can ALLEY Cloud really SSH into my Raspberry Pi?

Not from this static page. A real implementation needs an authenticated backend or private tunnel, careful SSH key handling, device authorization, and access controls. The terminal shown here is simulated and never connects to a device.

Will the website be hosted on my Raspberry Pi?

That is the intended use case: your Pi can serve your own site, while the service helps with setup and domain routing. Public hosting from home depends on uptime, bandwidth, router/ISP restrictions, TLS, and a secure networking design.

Do I get a domain with a paid plan?

The current mockup proposes an ALLEY Cloud subdomain on Free and custom-domain connection on paid plans. Whether a paid plan includes domain registration or only domain connection is a business decision to finalize before launch.

Are these prices and limits final?

No. They are sample values to illustrate the plan ladder. Update them after calculating Gemini API costs, domain costs, support needs, storage requirements, and the real limits of the Raspberry Pi connection service.
